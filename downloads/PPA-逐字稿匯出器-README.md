# PPA 逐字稿匯出器

版本：1.3.3

這是適用於已登入 PressPlay Academy 的 Chrome 本機擴充功能。它只讀取你帳號原本能觀看的課程單元；逐字稿不會上傳到其他網站。

## 安裝

1. 解壓縮 `ppa-transcript-exporter-v1.3.3.zip`。
2. 在 Chrome 開啟 `chrome://extensions`。
3. 開啟右上角「開發人員模式」。
4. 點「載入未封裝項目」，選取解壓後的 `ppa-transcript-exporter` 資料夾。
5. 建議將擴充功能釘選到 Chrome 工具列。

## 使用

1. 打開任一 PressPlay 課程單元頁，點工具列 PPA 圖示開啟右側面板。
2. 面板會偵測課程並顯示按目錄順序排列的單元。
3. 點「收集偵測到的字幕（不下載）」。
4. 等待每個單元顯示完成、找不到字幕或略過。
5. 可逐檔下載 VTT，或按「下載已收集字幕 ZIP」一次下載全部。

## 狀態與按鈕

- 待收集：尚未開始。
- 收集中：正在讀取該單元。
- 完成：已成功取得 VTT。
- 找不到字幕：可點 ↻ 只重新偵測該單元。
- ×：只從右側清單移除該單元，不會刪除本機檔案或課程內容。

## 注意

- ZIP 下載只會產生一個下載項目，可避免逐檔跳出儲存提示。
- 若 Chrome 開啟「下載前詢問儲存位置」，仍會在下載 ZIP 時詢問一次位置。
- 本工具匯出的是 `.vtt`，可用於 YouTube 與支援 WebVTT 的剪輯工具。
