使用原則

只整理自己的已購課程與獲授權教材

各平台可用的離線、教材與字幕功能，會依課程、訂閱與授權而不同。請以課程頁和官方 App 顯示的選項為準。

PRESSPLAY ACADEMY

PressPlay

此處可放入你自己的課程整理流程、教材位置與字幕整理筆記。

  • 登入自己的課程頁後，先查看課程附件與平台提供的功能。
  • 需要更新 PPA 逐字稿工具時，從工具的正式發布頁取得新版。
前往 PressPlay 官方網站 →

HAHOW

Hahow

在已購課程頁查看附件與教材；如需離線觀看，使用 Hahow 官方 App 提供的功能。

前往 Hahow 官方網站 →

KNOWLEDGE SATELLITE

知識衛星

從已購課程頁或官方 App 確認可下載的教材、字幕與離線觀看選項。

前往知識衛星官方網站 →

SHIFU

師父

依課程頁與官方 App 所列的下載、離線或教材功能操作；找不到時請向課程客服確認授權。

前往師父官方網站 →

如何更新

在 GitHub 編輯後，網站會自動發布

  1. 按頁面右上角「在 GitHub 編輯內容」。
  2. 編輯這份內容並按「Commit changes」。
  3. 等候約一分鐘後重新整理本頁，即可看到更新。
